# За одним столом

Семейное меню Кати и Лизы на 30 дней, перенесённое из предоставленных документов Word. Статический сайт без сборки, сторонних шрифтов, CDN и серверной базы данных.

## Запуск

Из корня репозитория: `python3 -m http.server 8000`. Открывайте сайт через HTTP: загрузка `data.json` через `file://` не поддерживается.

## Возможности

- Два профиля, точные порции, десерты и КБЖУ Лизы, отдельное меню Кати с порциями по аппетиту.
- Обычный календарь с реальными днями недели, переходом между месяцами, кнопкой «Сегодня» и горизонтальной лентой дат. Меню начинается заново 1-го числа каждого месяца; 31-го используется день 1, в феврале доступны только существующие даты.
- Редактор каждого приёма пищи: несколько позиций, свои названия, состав и калории на порцию; выбор из исходных и сохранённых блюд. Изменения независимы для каждого профиля и дня, доступен возврат к документу.
- 25 рецептов, подборки на выбранный день и на завтра, глобальный поиск.
- Общая бакалея и 9 походов в магазин: 227 пунктов, группировка из документа и по связанным блюдам.
- Отметки, сброс текущего списка и последовательная отмена действий (история отмены — до перезагрузки).

Выбранный профиль, дата, покупки, правки меню и библиотека блюд хранятся в localStorage этого браузера. Между устройствами синхронизации нет. Вкладки одного браузера обновляют покупки через событие storage. Группировка по блюдам не пересчитывает количества: они всегда на весь поход. Обновлённые документы задают калории, БЖУ, граммовки и десерты для Лизы; Катя ориентируется на аппетит. В завтраках Лизы учтён кофе с 50 мл молока.

## Публикация

Workflow `.github/workflows/pages.yml` публикует статические файлы при push в `main`. В Settings → Pages источником должен быть GitHub Actions. Дополнительные зависимости и секреты не требуются. Рабочая копия задачи уже изолирована: создавать дополнительные worktree для запуска не требуется.

## Проверки

`python3 -m unittest discover -s tests -v` проверяет полноту переноса меню и списков. `node --check app.js` проверяет синтаксис. Для функциональной проверки используйте браузер: выбор профиля, календарь, поиск, изменение и отмена покупок, перезагрузка страницы.

## Калории после редактирования

Без правок профиль Лизы показывает итог дня и БЖУ из обновлённого документа. Калорий отдельных приёмов пищи источник не содержит. После любой правки итогом становится сумма вручную указанных калорий всех позиций дня. Пока калории указаны не везде, сумма явно помечена как неполная. Пустое поле отличается от нуля. Исходная дневная калорийность Лизы остаётся справкой, БЖУ не пересчитываются. Кофе, напитки и десерты в изменённом меню включайте в калории позиции или добавляйте отдельно. Для Кати также можно вести свои калории вручную.

Имена и калорийность новых блюд сохраняются при сохранении приёма пищи и доступны в подсказках на другие дни. Сохранённая калорийность относится к указанной порции и не масштабируется автоматически. Правки меню не пересчитывают список покупок из документа.

Функциональный тест редактора: при запущенном локальном сервере выполните `python tests/browser_workflow.py`. Нужны Python Playwright и Chromium (путь можно задать через `CHROMIUM_PATH`).

## Календарь и профили

Дата «Сегодня» определяется по Москве. При первом открытии выбран текущий день; затем сохраняется последняя выбранная дата. Время приёмов пищи в будни и выходные определяется по реальному дню недели, а не по подписи в исходном плане. Исходные меню повторяются ежемесячно; ручные изменения относятся к конкретной дате и профилю. Покупки сохраняются отдельно для каждого месяца. Старые правки перенесены на фактические даты относительно ранее выбранной даты начала; старые отметки покупок сохранены в выбранном месяце.

Аватары профилей — сгенерированные реалистичные котята, декоративные значки — SVG. Иконка приложения подготовлена по приложенному изображению, используется в шапке, favicon и Web App Manifest. Файлы хранятся локально в `assets/`, внешние сервисы для отображения не нужны.

Проверка календаря и переноса сохранений: `python tests/browser_calendar.py` при работающем локальном сервере. Тест проверяет реальные смещения дней недели, переходы месяцев, високосный февраль, кнопку «Сегодня», повторение меню и независимость месячных списков.
